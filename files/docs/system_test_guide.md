# 💎 简易个人多源网盘全功能测试指南

欢迎来到全功能自动化测试环境！你可以通过测试以下模块验证系统的所有核心特性：

---

## 🔑 1. 权限解锁与只读保护测试
- **游客只读保护**：默认状态下，顶部工具栏与侧边栏的上传、新建、重命名、移动、删除等按钮自动隐藏，文本框为 `readonly`。
- **密码解锁管理**：点击右上角 **`🔒 游客模式 (点击解锁)`**，输入默认密码 `admin`，即可解锁全套修改、上传与剪贴板权限！

---

## 📂 2. 多标签页与多格式预览测试
- **多标签页**：点击左侧不同文件，右侧顶部标签栏会同时打开多个选项卡，支持随意无缝切换与 `×` 关闭。
- **Markdown 视图切换**：点击右上角 **【渲染预览】** / **【编辑代码】** 进行可视化切换。
- **全格式支持**：支持嵌入阅读 **PDF 文档**、**高清图片**、以及 **带行号与 Tab 缩进的代码编辑器**！

---

## 📤 3. 上传与克隆复制测试
- **上传文件**：支持拖拽或选择单/多个本地文件上传。
- **上传整个文件夹**：支持选择本地整个文件夹，保持多级目录层级与文件嵌套自动上传！
- **深拷贝复制**：悬浮任意目录或文件节点，点击 📋 **复制**，然后在目标目录点击 📋 **粘贴副本**！

---

## 🗑️ 4. 回收站 60 天自动倒计时
- 移入回收站的项目自动精准记录删除时间并计算剩余保存天数（缺省保留 2 个月/60 天）。
- 支持随时在回收站弹窗中选择 **一键还原** 或 **彻底删除**！
